Principais formatações:

Negrito ou Destaque

Nessa frase temos um termo em Negrito usando a tag <b> (não semântica).

Nessa frase temos um termo em Destaque usando a tag <strong> (semântica).

Itálico / ênfase

Nesta frase temos um termo em Itálico usando a tag <i> (não semântica).

Nesta frase temos um termo em ênfase usando a tag <em> (semântica).

Texto marcado

Podemos também criar um texto marcado com a tag <mark>

Texto grande ou pequeno

Estamos criando um texto grande e um texto pequeno nesse parágrago.

Texto Deletado

Podemos marcar um texto como excluído para indicar que ele deve ser lido, mas não considerado

Texto Inserido

Podemos marcar um texto como inserido para uma ênfase e indicar que ele foi adicionado depois

Textos Subscritos

Para inserir coisas do tipo x20

Textos Sobrescrito

Para inserir textos do tipo H20
